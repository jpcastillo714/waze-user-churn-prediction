## 1. Contexto del Negocio

Waze es una de las aplicaciones de navegación comunitaria y tráfico en tiempo real más grandes del mundo, cuyo valor depende de la participación activa de los conductores que reportan incidentes viales.

### Problema de Negocio
Un segmento significativo de usuarios reduce paulatinamente su frecuencia de conducción o desinstala la aplicación tras enfrentar experiencias viales negativas. Waze necesita un modelo de Machine Learning que prediga la probabilidad de **abandono (*churn*)** de los conductores con suficiente antelación para activar estrategias proactivas de retención.
